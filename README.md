# Установка расширения в Chrome

## Почему появляется ошибка с `_Экспорт_...csv`
Chrome **не загружает расширение**, если внутри выбранной папки есть файл или директория,
чьё имя начинается с символа `_`.

Ошибка вида:

`Cannot load extension with file or directory name _.... Filenames starting with "_" are reserved...`

означает, что вы выбрали не «чистую» папку расширения (часто это `Downloads`, где лежат лишние файлы).

## Как загрузить правильно
1. Создайте отдельную папку, например `web_config_extension`.
2. Скопируйте в неё только файлы расширения:
   - `manifest.json`
   - `background.js`
   - `popup.html`
   - `popup.js`
   - `tz.txt`
   - CSV-файлы данных (`sites.csv`, `LNCEL_KR_RO.csv`, `Config_2G.csv`, `4G_ANT.csv`, `OPT_Speed.csv`, `RDB.csv`, `Nokia_Check_sync_BS_and_Verification_parameters.csv`)
3. Убедитесь, что в этой папке **нет** файлов/папок, начинающихся с `_`.
4. Откройте `chrome://extensions` → включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение» и выберите именно эту папку.

## Что исправлено в проекте
Из `manifest.json` удалена ссылка на отсутствующий `logo.ico`, чтобы исключить дополнительную ошибку при загрузке манифеста.
